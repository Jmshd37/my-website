# RBM / RISE Week photos

Upload portfolio photos here using these exact filenames:

- `rise-week-cover.jpg` — main RBM/RISE Week cover photo
- `hkust-gz.jpg` — HKUST (Guangzhou) campus, lecture or laboratory photo
- `xpeng.JPG` — XPeng visit photo
- `dji.JPG` — DJI visit photo
- `pony-ai.JPG` — Pony.ai visit photo

Recommended:
- JPG or WebP exported as JPG
- landscape orientation
- at least 1200 px wide
- keep each file reasonably compressed for faster page loading

The original JPEGs are preserved. The portfolio now renders same-stem `.webp` variants with a maximum dimension of 1280 pixels and `-640.webp` variants for smaller displays. Update the image paths and actual dimensions in content.json if replacing these derivatives. Filename case matters on GitHub Pages. Derivatives omit the originals' embedded metadata.
