# Jamshidbek Nurmukhammadov — Portfolio

Personal portfolio / online CV built as a lightweight static website.

## Structure

- `index.html` — page content and semantic structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, section highlighting and scroll reveals
- `favicon.svg` — browser icon

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

In the repository on GitHub:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the **main** branch and **/(root)** folder.
4. Save.

GitHub will then publish the site from this repository.

## Updating content

Most personal information is in `index.html`. Styling is kept separately in `styles.css` so content updates do not require redesigning the page.
